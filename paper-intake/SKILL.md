# 论文入库与阅读

用户提供论文 PDF 并要求阅读、分析或入库时，按本流程完成。创建论文笔记时读取并执行同级 `psocm/SKILL.md` 的完整分析要求；不以简短摘要代替。用户指定其他阅读深度或输出结构时，以其指令为准。

## 1. 核对材料与命名

- 读取 PDF 原文及可核实的出版信息，提取完整标题、作者、发表年份、会议和已有简称；不凭文件名臆测。检查 `70_Papers`、`30_Refereces/Papers` 和 `40_attechment/paper` 中是否已有同一论文或同名文件；检查全 vault 同名笔记。重复时沿用已有材料并保留个人内容，不覆盖不同论文。
- PDF 平铺复制到 `40_attechment/paper/`，命名为 `[<conference>'<yy>]{<简称>}<完整标题>.pdf`，如 `[AAAI'26]{AutoMalDesc}Large-Scale_Script Analysis_for_Cyber_Threat_Research.pdf`。会议缩写、年份和简称须有依据；没有已有或用户指定的简称则省略花括号及其内容；会议或年份未知时省略未经确认的前缀。标题可用下划线代替空格，替换路径分隔符等不适用字符。保留用户提供的原始文件，不移动或覆盖。
- 笔记直接放在 `70_Papers/`，不建论文或会议子目录。已知会议和年份时用 `<conference><yy>-<简称>.md`，如 `AAAI26-AutoMalDesc.md`；没有简称时用可辨识的简短标题，不将其伪装为论文已有简称；会议年份未知时不猜测前缀。清理 `/`、`\\`、`:`、`|`、`#`、`[`、`]` 等不适合链接或文件名的字符。同名不同材料加入简短区分信息。

## 2. 创建论文笔记

从原始 PDF 而非摘要推断论文内容；提取文本不完整或图表、公式有歧义时查看对应页面。按 PSOCM 六部分写入分析，保留九宫格、L→O→C→M 对应关系与原文位置；区分作者主张、基于证据的分析和证据缺口。引用的外部文献按 psocm 核实。不能读到完整原文时明确范围，不虚构完整分析。

笔记以 YAML frontmatter 开头，使用下面字段；保留全文原标题，未知信息用示例中的空值，`added` 是首次入库时 Asia/Shanghai 当地时间，后续不改。`created` 使用 vault 格式。`source` 指向实际存入的 PDF，链接必须加引号；标签遵循 `01_Dashborad/TagsList.md`，无合适标签时用空列表。阅读程度和功能性标签尚未统一定义，不自行发明或宣称用户已读；可在正文说明“AI 基于原文分析”，不冒充个人感受。

已核实会议或期刊及发表年份时，按 `01_Dashborad/TagsList.md` 的论文会议与期刊标签规则在 `tags` 中加入标签；不将具体标签逐一加入清单。发表场所或年份未核实则不猜测。

```yaml
---
created: YYYY-MM-DD HH:MM
title: "论文完整原标题"
type: paper
authors: []
year: null
added: YYYY-MM-DDTHH:MM:SS
source: "[[40_attechment/paper/实际文件名.pdf]]"
url: ""
tags: []
---
```

在 frontmatter 之后、PSOCM 正文之前，单独写一行指向实际原文 PDF 的 Obsidian 双链：

[[40_attechment/paper/实际文件名.pdf]]

正文双链与 frontmatter 的 `source` 均须指向同一份实际 PDF。

已有笔记时先检查内容与来源；保留用户原文、引用段落、已有时间及个人记录，按请求补充分析，不覆盖。不要批量迁移历史笔记。

## 3. 记录当日日记

读取系统在 Asia/Shanghai 的当前日期，更新 `10_Timeline/Daily/YYYY-MM-DD.md`，在 `## Research` 下的 `### Paper` 中追加一行 `阅读[[论文笔记名称]]`，双链指向本次论文的 note。若该小节不存在，在 `## Research` 下创建；已有小节则复用。此行是论文阅读记录入口，不据此推断用户已亲自阅读或阅读程度，不编造个人感受。保留所有已有内容及 `>` 段落，不创建待办复选框。若无当日日记，按 `99_System/Templates/Daily_Template.md` 创建，替换日期和时间占位符，保留既有 daily 标签及模板结构；不得覆盖现有文件。

## 4. 检查

核对 PDF 与输入文件内容一致、目标路径及命名正确、笔记 YAML 可解析且 source 和正文开头双链均指向实际 PDF、已核实的会议或期刊年份标签已按清单规则写入笔记、当日日记 `## Research` 的 `### Paper` 下有指向笔记的阅读双链、PSOCM 分析已实际写入并包含证据位置。报告实际创建或更新的文件、分析覆盖范围和无法核实的内容。遇到同名冲突或来源信息不足时保守处理并说明，不覆盖原文件。
